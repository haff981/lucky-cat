# 🐱 Lucky Cat — $LUCKY

Fortune favors the cat.

Lucky Cat is a lucky-cat meme coin. Simple as that: cats sell, dogs sell,
and a fortune cat brings luck to everyone who holds it.

## The coin

- **Name:** Lucky Cat
- **Ticker:** $LUCKY
- **Chain:** Solana
- **Launch:** [forks.wiki](https://forks.wiki) — one coin per repository,
  launched on this repo via pump.fun

## How it works

This repository is the home of the $LUCKY coin. Its creator fees are split
on-chain, for good, between the people behind the code:

- 70% — repository owner
- 5% — top contributors
- 10% / 3% / 2% — parent, grandparent and great-grandparent repositories
  up the fork line
- 10% — forks treasury

Nobody can change the split later — not even forks.
